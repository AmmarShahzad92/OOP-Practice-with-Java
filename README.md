# OOP Practice with Java

This repository is a collection of Java projects and exercises designed to reinforce the principles of Object-Oriented Programming (OOP). It provides hands-on examples for core OOP concepts.

## Key Topics Covered

*   **Inheritance (`personInherit`)**: Demonstrates how a class can inherit fields and methods from another class.
*   **Polymorphism (`EmployeePolymorph`)**: Shows how objects of different classes can be treated as objects of a common superclass, with methods behaving differently based on the object's actual type.
*   **Interfaces (`EmployeeInterface`)**: Contains examples of using interfaces to achieve abstraction and define contracts for classes.
*   **Type Casting (`TypCast`)**: Includes examples of upcasting and downcasting between classes.
*   **File Handling (`FileHandling`)**: Provides examples of reading from and writing to files in Java.

This repository serves as a practical guide for anyone looking to strengthen their understanding of OOP in Java through coding exercises.
